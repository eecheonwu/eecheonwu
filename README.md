# Eecheon Wu — Research & Projects

Welcome — I'm focused on Agentic Software Engineering, AI research, and building AI-native systems that integrate planning, governance, and execution through a Single Source of Truth (SSOT).

**Featured project (current): EIP MCP Server**

- Repository: https://github.com/eecheonwu/eip-mcp-server
- Summary: The EIP MCP Server bridges local development and the Engineering Intelligence Platform (EIP). It exposes local workspace orchestration tools to AI coding assistants (IDE agents) via the Model Context Protocol (MCP) and a background webhook listener. This enables AI agents to scaffold SSOT artifacts, generate implementation/task/test/security plans, and synchronize local documentation back to the EIP knowledge graph.

Quick install (runs the MCP server for IDE agents):

```bash
uvx --from git+https://github.com/eecheonwu/eip-mcp-server.git eip-mcp-server
```

See the EIP MCP Server README for full installation, IDE configuration, and architecture requirements.
